# Tavoos visual identity / هویت بصری طاووس

An original geometric peacock fan paired with a handset: multiple ways to connect, gathered around one call button. Drawn as native vector paths for this repository; not derived from the WhatsApp mark. Third-party channel logos remain their owners’ marks.

نشان اختصاصی از بادبزن پرهای طاووس و گوشی تلفن ساخته شده است: چند راه ارتباطی پیرامون یک دکمه. مسیرهای برداری از ابتدا برای این مخزن طراحی شده‌اند و از نشان واتساپ کپی نشده‌اند.

Primary purple: `#5F01AF`; ink: `#251136`; paper: `#F7F2FC`; secondary text: `#62566E`. Use clear space of at least one feather width. Keep proportions; do not add gradients, shadows or third-party marks inside the logo. The banner uses DejaVu Sans with Arial/sans-serif fallbacks. SVG text stays editable, so installed fonts can affect rendering; the PNG is the fixed reference.

رنگ اصلی بنفش `#5F01AF` است. نسبت ابعاد و فضای خالی اطراف نشان را حفظ کنید. متن بنر قابل ویرایش است؛ نسخه PNG مرجع نمایش ثابت است.
